# Author & Repository Formatting Guidelines

When creating or updating `README.md` or repository documentation:
- Do NOT include generic open-source contribution boilerplate text (e.g., "contributions welcome, feel free to check the issues page").
- Always format the Author and License sections as follows:

```markdown
## 👤 Author

Developed by **Pratham** ([@prathaam17](https://github.com/prathaam17))

## 📜 License

This project is licensed under the [MIT License](LICENSE).
```
